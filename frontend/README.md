# Frontend React - Annuaire CBCA

Interface React/Vite de l'annuaire CBCA.

## Demarrage

```bash
npm install
copy .env.example .env
npm run dev
```

URL locale :

```text
http://localhost:5173
```

## Fonctionnalites

- recherche instantanee par nom, degre ou poste
- filtres rapides pour les reverends et les regions
- boutons `tel:` et WhatsApp sur chaque fiche
- navigation mobile en bas
- espace admin pour creer les postes
- espace admin pour ajouter les pasteurs
- support PWA avec manifest et service worker
